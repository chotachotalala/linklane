# HTTP API

API используется тем же интерфейсом и не включает анонимное создание ссылок.
Сначала откройте `/setup` локально и создайте владельца, затем используйте `/login`.
Для API требуется подписанная cookie-сессия; изменяющие запросы дополнительно требуют
заголовок `X-CSRF-Token` со значением из `<meta name="csrf-token">` текущей страницы.
`Origin`, если он присутствует, должен совпадать с `LINKLANE_BASE_URL`.

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/healthz` | Состояние HTTP-сервиса |
| POST | `/api/setup` | Первичное создание владельца, только локально |
| POST | `/api/login` | Вход по паролю |
| POST | `/api/logout` | Завершение текущей сессии |
| POST | `/api/password` | Смена пароля с отзывом прежних сессий |
| GET | `/api/overview` | Все ссылки и сводная аналитика |
| POST | `/api/links` | Создание ссылки |
| PUT | `/api/links/{slug}` | Изменение назначения, названия, метки, срока и активности |
| DELETE | `/api/links/{slug}` | Удаление ссылки и её статистики |
| GET | `/api/links/{slug}/qr.svg` | QR-код для скачивания |
| GET | `/api/export.csv` | Экспорт текущего списка |
| GET / HEAD | `/s/{slug}` | Публичное перенаправление, 302 |
| GET | `/p/{slug}` | Публичный предпросмотр конечного адреса |

Тело создания / изменения:

```json
{
  "title": "Моё портфолио",
  "destination": "https://example.com/portfolio",
  "slug": "portfolio",
  "tag": "Личное",
  "active": true,
  "expires_at": null
}
```

`slug` можно опустить при создании. В PUT существующий короткий адрес сохраняется независимо
от переданного поля `slug`. Изменение адреса намеренно не предусмотрено, чтобы не ломать
ранее отправленные ссылки. `expires_at` — Unix timestamp в секундах или `null`.

HTTP-ответы: 201 — создано, 400 — неверные данные, 401 — нужен вход, 403 — нет доступа / CSRF,
404 — нет объекта, 409 — адрес занят, 410 — ссылка отключена или истекла, 413 — тело больше 16 КиБ,
429 — ограничение попыток входа. Ошибки API имеют вид `{"error":"Описание"}`.

HTML-предпросмотр и HEAD не увеличивают счётчик. GET перенаправляет на внешний сайт;
сам сервер содержимое внешнего сайта не загружает.
