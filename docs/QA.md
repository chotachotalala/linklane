# Проверка выпуска 1.0.0

Дата: 18 ноября 2026. Среда: Windows 11 x64, Python 3.14.10, FastAPI 0.164.0,
Starlette 1.10.0, SQLite; браузер Chromium внутри Codex.

## Автоматически

- **38 тестов прошли**: полный жизненный цикл ссылок, случайные адреса,
  регистр / конфликты, истечение срока, пауза, HEAD / предпросмотр, QR, CSV,
  приватность полей аналитики, вход, CSRF, Origin, Host, лимит попыток,
  отзыв сессий после смены пароля и локальное восстановление доступа.
- 18 одновременных GET-переходов записаны без потери счётчика.
- 25 случайно сгенерированных адресов проверены реальным обработчиком перенаправления.
- `ruff check .`: замечаний нет. `node --check .../app.js`: синтаксис корректен.
- Один deprecation warning относится к совместимости тестового клиента Starlette с httpx;
  тесты проходят, на работу HTTP-сервера предупреждение не влияет.

## В браузере

- Вход в демонстрационный кабинет, создание собственного адреса.
- Редактирование названия, сохранение паузы и поиск по короткому адресу.
- Открытие QR-кода, страницы аналитики и переключение разделов.
- Проверены широкая компоновка 1440 px и мобильная 390 px.
- Устранено горизонтальное переполнение страницы, вызванное скрытой подписью таблицы.
  На мобильном горизонтальная прокрутка остаётся только внутри таблицы.
- Добавлена доступная на мобильном кнопка выхода.
- В журнале браузера нет ошибок JavaScript.
- Сохранены снимки реального UI с демонстрационными данными в `docs/assets`.

## Пределы проверки

Dockerfile / Compose подготовлены, но Docker-сборка и внешний HTTPS reverse proxy не запускались.
GitHub Actions ещё не запускался на GitHub, публичный сервер не размещался.
Независимого аудита безопасности и нагрузочного тестирования не было.

Все базы для автоматических проверок временные. Демонстрационная база изолирована.
Учебные программы пользователя не запускались и не изменялись.
