# Самостоятельное размещение

Локальный запуск уже работает без хостинга. Этот документ описывает подготовленный способ
разместить сервис на собственном сервере; удалённое размещение агентом не выполнялось.

## Обычный Python

1. Установите приложение в отдельное окружение и создайте владельца:

```bash
python -m linklane --init-admin
```

Пароль запрашивается скрыто. Для продакшена не используйте демонстрационные данные.

2. Укажите адрес своего сервера и Secure-cookie:

```bash
export LINKLANE_BASE_URL=https://links.example.com
export LINKLANE_SECURE_COOKIES=1
export LINKLANE_DATA_DIR=/path/to/private/data
```

Если при создании владельца использовали другой каталог, переместите его при остановленном
сервисе или задайте одинаковый `LINKLANE_DATA_DIR` на обоих шагах.

3. Запустите приложение за HTTPS reverse proxy:

```bash
python -m linklane --host 127.0.0.1 --port 8787
```

Сервис слушает loopback. Reverse proxy принимает внешний HTTPS-трафик и передаёт исходный Host.
Пример Caddy для установленного на том же сервере proxy:

```caddy
links.example.com {
    reverse_proxy 127.0.0.1:8787
}
```

Замените домен на свой и настройте его DNS. Размещение на сервере, DNS, сертификат и внешний
доступ зависят от вашей инфраструктуры. Заголовки `X-Forwarded-*` по умолчанию не принимаются;
адрес коротких ссылок берётся только из настроенной переменной, а не из запроса.

## Docker Compose

Dockerfile и Compose подготовлены; Docker-сборка в этой среде не запускалась.

```bash
docker compose build
docker compose run --rm linklane python -m linklane --init-admin
LINKLANE_BASE_URL=https://links.example.com docker compose up -d
```

На Windows переменную можно задать перед запуском в PowerShell:

```powershell
$env:LINKLANE_BASE_URL='https://links.example.com'
docker compose up -d
```

Compose публикует порт только на `127.0.0.1:8787`. Доступ снаружи организуется HTTPS reverse proxy.
Данные находятся в volume `linklane-data`. Внешний HTTP без TLS для кабинета не используйте.

## Эксплуатация

- Один владелец, небольшой личный сервис. Публичная регистрация и биллинг не реализованы.
- Делайте резервную копию всего каталога данных при остановленном приложении.
- Не публикуйте `.session-key`, базу данных, рабочие CSV или личные ссылки в Git.
- Включите ограничение размера запросов и частоты обращений на reverse proxy.
- Пароль можно восстановить через локальный `python -m linklane --reset-password` с тем же каталогом данных.
- Демо нельзя запускать на внешнем интерфейсе. Его пароль известен всем.
- Для высокой нагрузки, нескольких независимых владельцев или нескольких хостов нужен отдельный проект масштабирования.
